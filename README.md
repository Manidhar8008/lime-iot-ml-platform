# 🚀 Lime IoT ML Platform: End-to-End Micromobility Analytics

**Production-ready machine learning platform combining IoT data streams, quantitative finance models, and advanced analytics for fleet optimization.**

## 🎯 Project Overview
- **Real-time data processing** from Lime's GBFS API (500K+ events/day)
- **Advanced ML models**: LSTM, XGBoost, Prophet ensemble forecasting
- **Quantitative analysis**: GARCH volatility, VaR, portfolio optimization
- **Production deployment**: Docker, Kubernetes, MLOps pipeline
